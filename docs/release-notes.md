## v0.11.0 -Settings, User Preferences & Multilingual Foundation

**Module 11 -Released**

- User settings API (`GET/PATCH /api/settings`) -notification toggles, risk thresholds, preferred route type, dispatch confirmation window
- Per-user language preference (`UserRecord.preferredLanguage`)
- Company language settings: `preferredLanguage`, `supportedLanguages`, `fallbackLanguage`
- Language update APIs: `PATCH /api/company/language`, `PATCH /api/user/language`
- `useI18nCompany` hook for locale sync
- Settings page (`/settings`) with Company Profile and User Preferences tabs

---

## v0.10.0 -Operational Feed & Health Score

**Module 10 -Released**

- Operational feed API (`GET /api/operational/feed`) -time-ordered company-scoped event aggregation
- Operational health score API (`GET /api/operational/health`) -0–100 score with five-tier label
- `feed:updated` and `health:updated` Socket.io events
- 30-second polling fallback for serverless deployments
- `OperationalHealthScore` type with Excellent / Good / Fair / Poor / Critical labels

## v0.9.0 -Executive Analytics & Reporting

**Module 9 -Released**
